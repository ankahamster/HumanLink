HumanlinkPay Demo

可视化演示 `Hermes -> HumanlinkPay Gateway -> HumanLink SDK -> Sepolia Native Transfer` 的完整链路。当前风险阈值固定为 0.001 Sepolia ETH。

低风险: `amount <= 0.001 ETH` 自动放行
高风险: `amount > 0.001 ETH` 触发 HumanLink
成功授权后自动打开 `humanlink_record_url`

Hermes 对话窗口

这里模拟你和 Hermes 的自然聊天。聊天记录会保存在浏览器本地，刷新或重启 gateway 后仍然会保留。

只要一句话里包含地址、金额和支付语义，Hermes 就会自动解析，并把交易请求填到右侧表单里。

交易请求

Hermes 解析出的地址、金额、用途会自动填到这里。字段齐全后会默认自动发给 gateway；你也可以手动修改后再重新发起。

`DENY`：地址不在 allowlist，策略直接拒绝
`ALLOW`：金额 `<= 0.001 ETH`，不触发 HumanLink
`REQUIRE_HL`：金额 `> 0.001 ETH`，触发 HumanLink 指纹授权

当前展示的是 `REQUIRE_HL` 示例：收款地址在 allowlist 且金额超过阈值，会触发 HumanLink SDK 指纹授权。

推荐演示顺序：`DENY` -> `ALLOW` -> `REQUIRE_HL`。
